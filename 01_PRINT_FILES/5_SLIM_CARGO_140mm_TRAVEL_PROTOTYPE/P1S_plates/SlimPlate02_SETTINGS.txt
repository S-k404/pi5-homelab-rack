SlimPlate02 (PETG): 3U module + 3 base bars
===========================================
Status: ALTERNATIVE rack. Print the Slim plates 01S-07S INSTEAD of Plate01-07 of the standard rack, not as well.
It's not in the Robu order. The 12 V brick cradle (plate 13) does not fit this rack: see ../README.md.
Material: PETG, about 230 g  (the Slim README lists PETG / ABS / ASA; ABS / ASA need the enclosure closed too)

How: double-click the .3mf (or File > Open Project in Bambu Studio). Every part is already placed.
If Bambu Studio asks, choose to load the geometry only. Then pick the settings below and Slice.

Settings (Bambu P1S): 0.20mm Standard @BBL P1S, Generic PETG, 4 walls, 25% gyroid, supports OFF (see Notes),
Textured PEI no glue, enclosure CLOSED.

Notes:
  Supports OFF: the joint bosses and key slots have small overhangs, the same as the standard rack's modules
  (Slim check: 03_CHECKS/VERIFICATION_slim-cargo_plates_28Oct.txt). If a boss looks ragged, turn on tree supports
  for that plate only.
  Base bars: right-click each > Wall loops 5, Sparse infill 30%.
  The bars are 223 mm long and lie straight on this plate. The loose SlimCargo_BaseBar_x3.stl is saved at 45 deg
  so it fits a 220 mm bed; on the P1S use this 3MF.

On this plate:
  - Base bar x3   (SlimCargo_BaseBar_x3.stl)
  - Side 3U x1   (SlimCargo_SideModule_3U_x4.stl)
Hardware for the whole rack: 48 x M5 x 12 button head + 48 M5 heat-set inserts (the same as the standard rack).
