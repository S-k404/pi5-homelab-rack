03_PLA_PRINT-FIRST_3U-module+handles
====================================
Status: print FIRST (insert test)
Material: PLA, about 176 g

How: double-click the .3mf (or File > Open Project in Bambu Studio). Every part is already placed.
If Bambu Studio asks, choose to load the geometry only. Then pick the settings below and Slice.
(The loose STLs are here too, in case you'd rather import them yourself.)

Settings:
  - Bambu Studio profile: 0.24mm Draft @BBL P1S
  - Filament: Generic PLA
  - Wall loops: 3 (default is 2)
  - Sparse infill: 15% gyroid
  - Supports: OFF
  - Plate: Textured PEI
  - Enclosure: top lid or front door OPEN (PLA heat-creeps in a closed P1S)

Notes:
  PRINT THIS PLATE FIRST. When it's done, heat-set one M5 insert into a rail hole and one into a joint boss
  (holes are 6.4 mm x 10 mm deep). If the insert is loose or bulges the wall, STOP: the hole size (INS_D)
  needs changing before the other rack plates are printed.
  Handles: in Bambu Studio right-click each handle > Wall loops 4, Sparse infill 20%.

On this plate:
  - Side 3U x1   (Rack_SideModule_3U_x4.stl)
  - Handle x2   (Rack_Handle_x2.stl)
